## Decisions

1. **`projects.recordings` is stored** (a `hasMany` relationship, "Recordings with a widget"). The instance stays derived from the stories, but a widget that has no story yet has no trace without it: after "Add a widget to a site" the recording page would say "Used in no project", which is the fault the owner named ("no relationship between projects and recordings"). Step 2 of the wizard and **Add to a project** write it; the Overview and the recording page show the union of these widgets and the projects with stories for the recording. A deleted recording leaves the list (FK `ON DELETE cascade`, tested).
2. **A refused `return` is kept, never followed.** The Annotate link keeps `return` as given (the forms send it on); only `projects.returnTarget` gives the way back. `stories.saveDraft` keeps a listed page as `toldOn` (as before) and any other http(s) page as `toldOnUnlisted` (operators only, never in WADM); a later listed page clears it.
3. **The preview page is the one page of the stack that `return` may name** (`returnTarget(…, { self })`, path `/admin/preview/` only). A story told from it has `toldOnUnlisted` = the preview page, so it does not tick "Paste the snippet into your site" and its mails go to Your stories.
4. **The admin previews have live links without a contract change.** `PreviewWidget` rewrites `return` of a click on an `<a href="…/annotate?…">` inside the widget to the preview page. It reads only CONTRACT §7.1 (the link is a normal `<a href>`). An alternative was a widget attribute for `return`; it would add contract surface for an admin need only.
5. **The range is a widget attribute** (`range`, part `range`, event `annoudio:range`), additive in v1: an overlay on the shadow DOM would couple the Annotate page to the private layout of the widget. The range takes no pointer and its edges do, so a drag anywhere (also over a story or inside the range) chooses a new range (wavesurfer cancels a drag selection that starts on a region: `.claude/rules/embed-wavesurfer-coupling.md` rules 5, 6).
6. **The snippet carries a fallback** `<audio controls preload="none" src>` (audit 10, CONTRACT §1 rule 5, additive): no request before the visitor plays it.
7. **Payload select and radio fields keep their type**; only their Field component is a native `<select>` (no schema change). Language stays text with a `<datalist>`: a language tag has no closed set.
