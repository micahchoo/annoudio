# 03-operator-try-it-preview

**Operator** · Recording page → Try it → preview page with the live widget → Open the Annotate page

On the recording page, the region "Widgets of this recording" shows the Annotate address and **Try it: tell a story**. Try it opens the Annotate page as a member sees it, with **Back to the site**; that link goes to the operator's preview page. There the live widget plays and opens a story. **Open the Annotate page** opens the member's page again.

Stumbles seen while recording:

- On a 1280 px screen the Annotate page is a narrow column at the left edge; two thirds of the window stay empty.
- "Back to the site" lands on the preview page scrolled down to the widget: the heading and the help line ("This is the widget as visitors see it…") are above the fold, so the operator does not see where they are.
